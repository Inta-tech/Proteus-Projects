# Digital System Design Projects

A collection of Digital System Design (DSD) projects implemented and simulated using **Proteus Design Suite**. This repository contains digital logic circuits, counters, arithmetic circuits, and automation systems developed as part of my academic learning and practical experimentation.

## 🚀 Projects Overview

### 1. 4-Bit ALU
A 4-bit Arithmetic Logic Unit designed to perform basic arithmetic and logical operations using digital ICs.

### 2. Digital Counter with Push Button
A digital counting circuit that uses push-button input to increment the counter and display the output.

### 3. Double Digit Counter with Reset Button
A two-digit digital counter capable of counting from 00 to 99, with a reset mechanism.

### 4. Single Digit Counter with Reset Button
A single-digit counter that displays values from 0 to 9 and supports resetting.

### 5. Start and Stop Digital Counter Using JK Flip-Flop
A digital counter featuring start and stop functionality implemented using JK flip-flop logic.

### 6. Water Tank Filling and Draining System
A DC motor-based water tank control system designed to simulate water filling, draining, and stopping operations.

### 7. Water Indicator With Automatic Motor
An automatic water-level indication and motor control system that uses digital logic to manage water-level operations.
